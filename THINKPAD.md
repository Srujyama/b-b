## Goal

BangBang (帮帮, "help") is an AI advocate for people the US healthcare billing system talks past. Demo story: Mrs. Lin, a Mandarin-speaking mom with no English, gets a $14k ER bill. She photographs it and talks to BangBang in Mandarin. BangBang (1) reads and explains the bill in Chinese and flags errors (duplicates, upcoding); (2) researches fair prices (Medicare rates, the hospital's price-transparency file, its legally required 501(r) financial-assistance policy) using Context.dev; (3) records her spending mandate on BNB Chain; (4) negotiates IN ENGLISH, out loud, against the hospital's billing agent (ElevenLabs voice, agent vs agent or a human playing billing), while she follows a live Mandarin transcript; (5) settles: the agreed amount sits in XRPL escrow and is released only when the hospital confirms a zero balance, with Credentials proving hardship eligibility and a devnet Vault+Loan community fund covering a 0% plan; (6) pays for its own data and tools per call in AUSD over x402; (7) uses Gemini Fed-decision odds to choose between a lump-sum discount and a payment plan. Mode 2 (clinics): a doctor's office uploads a denial and clinical notes, the agent pulls the payer's medical policy, builds the medical-necessity case and appeal letter, and argues it with the insurer's agent. DONE = this runs end to end from the web UI on testnets with real API calls (nothing hard-coded), a 2-minute demo path works, and the public repo README maps each sponsor track to the code that earns it.

## Constraints

- Nothing core is hard-coded: prices, odds, policies and on-chain state come from real API/chain calls. Seed data for the demo (the sample bill, the hospital agent's persona) is fine and labeled as such.
- Secrets live only in bangbang/server/.env (gitignored). Never commit keys or private keys.
- Every module must degrade loudly: if a key is missing, throw/return a clear 'X not configured: set Y' error. Never silently fake success.
- Testnets only: XRPL devnet/testnet, Base Sepolia, BSC testnet, Gemini sandbox. Never mainnet.
- New code lives in bangbang/. lowball-main/ is reference only (prior work); port ideas, don't edit it.
- **Max concurrency: 6** — 9 disjoint module tasks; cap parallel agents for token/RAM cost (machine had RAM pressure before)
